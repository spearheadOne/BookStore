# Local end-to-end testing

Run `source ./local-setup.sh` from the repository root to set the URLs and token variables used below.

## Content fixtures and download checks

Set the file paths from the repository root before running the upload commands. The RTF copies in the temporary
directory match the paths used in the recorded curls.

```bash
E2E_TMP=$(mktemp -d)
FIXTURE_DIR="$PWD/e2e/fixtures"

PDF_FILE="$FIXTURE_DIR/content-probe.pdf"
REPLACEMENT_PDF="$FIXTURE_DIR/content-replacement.pdf"
EPUB_FILE="$FIXTURE_DIR/content-probe.epub"
REPLACEMENT_EPUB="$FIXTURE_DIR/content-replacement.epub"
RTF_FILE="$E2E_TMP/first.rtf"
REPLACEMENT_RTF="$E2E_TMP/replacement.rtf"

cp "$FIXTURE_DIR/content-probe.rtf" "$RTF_FILE"
cp "$FIXTURE_DIR/content-replacement.rtf" "$REPLACEMENT_RTF"
```

The original and replacement PDFs have embedded text. The original contains `Docker Java`; the replacement contains
`Docker pdftextprobe`. The scanned-PDF result below came from a separate image-only file.

Save each download with `curl -o` and use `cmp` against the file uploaded for that format. After replacing a file,
compare its download against the replacement fixture. For example, after uploading `$REPLACEMENT_PDF`:

```bash
curl -fsS -w 'HTTP %{http_code}\n' \
  -H "Authorization: Bearer $BOOK_TOKEN" \
  -o "$E2E_TMP/download.pdf" \
  "$KONG/api/v1/books/$BOOK_ID/content?format=pdf" &&
cmp "$REPLACEMENT_PDF" "$E2E_TMP/download.pdf"
```

`HTTP 200` confirms the download succeeded. A silent `cmp` with exit status zero confirms the two files match byte for
byte. The cross-format checks compare the other downloads with their last successful uploads.
